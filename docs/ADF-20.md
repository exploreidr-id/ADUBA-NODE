# ADF-20

ADF-20 is the planned native/token standard for the ADUBA ecosystem.

Current native asset:
- Name: ADUBA
- Symbol: ADU
- Decimals: 18
- Target maximum supply: 1,000,000,000 ADU
- Post-genesis minting: disabled by current design

This document is a development specification, not a claim that a finalized public standard has been deployed.
